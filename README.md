# EduGrade

Web app untuk guru: **Ubah Nilai** di file Excel sendiri dan **Isi e-Rapor (T/R)** pada template resmi Kemendikdasmen. Akses unduh memakai kode sekali beli dengan kuota.

- `index.html`: aplikasi guru
- `admin.html`: panel Admin dan portal Affiliate
- `js/config.js`: **isi `GAS_URL` dan `WA_ADMIN` sebelum upload**
- `js/engine.js`: pengolah Excel di browser (data siswa tidak dikirim ke server)

Panduan lengkap: lihat `PANDUAN-INSTALASI.md`.

EduGrade bukan produk resmi Kemendikdasmen.
